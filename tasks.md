# Lore
Ты новый админ сервера в майнкрафт. В твой первый рабочий день уже что-то сломалось, в логах бардак, игроки жалуются, что их аккаунты украдены, увы но рагребать это всё придётся тебе... удачи

## 1. NULL nickname
Почему на сервере до сих пор нет скрипта приветствия новых игроков... Вдобавок кто-то смог найти уязвимость путём логина под "пустым" никнеймом, его уже нашли по IP и забанили, но нужно, чтобы впредь это не случалось

**Задача**: написать скрипт `welcome.sh`, который:
- принимает ник первым аргументом
- валидирует ник: длина в 3-16 символов и только буквы английского языка верхнего и нижнего регистров, цифр и нижнего подчеркивания (A-Z, a-z, 0-9, _)
- если ник невалидный, то скрипт выводи в stderr "Invalid nickname" и возвращает 1
- если ник валидный, то скрипт выводит в stdout "Welcome, \<nickname\>!" и возвращает 0

Примеры:
```
./welcome.sh "Aboba"       -> (stdout) "Welcome, Aboba!"
./welcome.sh "=^)"         -> (stderr) "Invalid nickname"
./welcome.sh ""            -> (stderr) "Invalid nickname"
```

Темы:
- shebang
- echo
- regex
- if-statment
- аргументы
- коды возврата
- потоки ввода-вывода

## 2. Енвироны
Предыдущий админ навёл minor refactoring, после которого сломалась конфигурация сервера. Судя по симптомам, кто-то забыл задать переменные окружения.

**Задача**: написать скрипт `check_environs.sh`, который:
- проверяет, определены ли переменные окружения SERVER_NAME, MAX_PLAYERS, SPAWN_COORDS
- если переменная не задана — записывает её в `server.conf` со значением по умолчанию:
SERVER_NAME="StarCraft"
MAX_PLAYERS=125
SPAWN_COORDS="274 67 -249"
- если переменная задана — оставляет как есть и записывает её в `server.conf`
- в конце выводит итоговый `server.conf`

Пример:
```
./check_environs.sh      -> содержимое server.conf
```

Темы:
- environs
- if-statement
- циклы
- работа с файлами

## 3. Дюп предметов
Кто-то нашёл способ дюпать ресы, но он не учёл, что на сервере ведётся лог операций. Нужно найти читера и узнать, как он нашёл этот хак, пока все на сервере не узнали об этом

**Задача**: написать скрипт `find_fraud.sh`, который:
- принимает лог с транзакциями первым аргументом
- читает лог транзакций (хранит информацию об операциях построчно в формате <from_nickname> -> <to_nickname> <amount> <item>, например, "Steve -> Lololoshka 23 emeralds")
- для каждого игрока считает доходы и расходы
- если расходы > доходов — пишет ник в stdout
- для обработки текста использовать `awk`

Пример:
```
./find_fraud.sh transactions.log    -> (stdout) "Steve"
```

Темы:
- арифметика
- циклы
- awk

## 4. Бан-лист

Один из игроков доказал, что его аккаунта взломали и гриферством он лично не занимался, поэтому необходимо вытащить его из бана. Но в бан-листе какой-то кошмар, хочется причесать его. Думается можно соместить две этих задачи

**Задача**: написать скрипт `ban_manager.sh`
с командами:
- `format <file>` — убирает дубли, удаляет из списка игрока с ником "11_Steve_11", перезаписывает файл (заменяет старый бан-лист новым)
- `add <nickname> <time> <reason>` — добавляет в бан (! нужно убедиться, что дублей не будет при добавлении новой записи !), причем аргументлв может быть три ("<nickname>" "<time>" "<reason>"), так и один ("<nickname> <time> <reason>")
- `info <nickname>` — выводит в stdout "<nickname> <time> <reason>"
- `remove <nickname>` — удаляет из бана игрока с указанным ником
- `sort --name <file>` — новый список, отсортированный по нику
- `sort --time <file>` — новый список, отсортированный по времени
в котором:
- каждое действие — отдельная функция: `format()`, `add()`, `info()`, `remove()`, `sort()`
- определение действия в первом аргументе — через `case`
- для обработки текста использовать `sed`

Примеры:

```
./ban_manager.sh format banlist.txt
./ban_manager.sh add "Herobrine 01:01:2025 cheating"
./ban_manager.sh add "Herobrine" "01:01:2025" "cheating"
./ban_manager.sh info Herobrine                       -> (stdout) "Herobrine 01:01:2025 cheating"
./ban_manager.sh remove Herobrine
./ban_manager.sh sort --name sorted.txt
./ban_manager.sh sort --time sorted.txt
```

Темы:
- функции
- case
- циклы
- sed
- сортировка

## 5. Отчёт
Владелец просит финальный отчёт по серверу за день ох

**Задача**: написать скрипт `report.sh`, который:
- выводит краткую информацию об утилите через флаг `--help`
- принимает имена файлов с логами через флаги
```
--players players.txt или -p players.txt
--banlist banlist.txt или -b banlist.txt
--transactions transactions.txt или -t transactions.txt
```
- создаёт лок-файл "report.lock"; собирает данные из файлов `players.txt`, `banlist.txt`, `transactions.log`; выводит отчет в файл `report.txt`; удаляет лок-файл
- отчет содержит кол-во зарегестрированных игроков на сервере из `players.txt`; кол-во забаненных на текущий момент игроков из `banlist.txt`; кол-во транзакций и самый популярный предмет, используемый при обмене, за день из `transactions.txt`
- корректно прерывает работу при получении сигналов SIGINT/SIGTERM -- если во время составления отчета пришёл один из сигналов, то удаляются файл с составляемым отчетом удаляется и файл-лок, а в stderr выводится сообщение "Reporting was interrupted"; скрипт завершает работу с кодом возврата 1
- если во время составления отчета ещё раз запустить скрипт, то в stderr выводится сообщение "Report in progress", и скрипт завершается с кодом возврата 1

**Формат отчёта** :
```
StarCraft server report

Players: <N>
Bans: <N>
Transactions: <N>
Top item: <item>
```

Пример:
```
./report.sh -t transactions.txt -p players.txt --banlist banlist.txt    -> report.txt
```

Темы:
- все темы из задач выше
- флаги
- сигналы
