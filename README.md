py-скрипты AI generated -- возможны некорректные тестовые данные или ошибки в чекере

Для генерации входных данных выполните:

python3 generate.py

---

Для валидации ответов выполните:

python3 check.py

---

Для очистки сгенерированного

python3 clean.py

! Применять острожно, т к затирает всё содержимое в диеркториях `task<n>`, включая файлы с написанными вами скриптами !
